# content-health
Use para medir prontidão editorial.
## Verificações
- Produtos sem preço, imagem, alt, estilo ou disponibilidade.
- Dados institucionais vazios.
- Equipe sem foto/cargo.
- Depoimentos sem origem/aprovação.
- Eventos sem fotos autorizadas.
- Páginas legais ausentes.
## Saída
Gerar lista de pendências; nunca preencher automaticamente com dados fictícios.
