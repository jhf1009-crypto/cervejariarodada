# scroll-animation
Use para motion/scroll.
## Regras
- Nada de scroll-jacking.
- Respeitar prefers-reduced-motion.
- Mobile simplificado; priorizar transform/opacity.
- Conteúdo essencial existe no HTML sem animação.
- Pin curto, no máximo cerca de 3 viewports.
- Lighthouse mobile não pode cair abaixo do orçamento definido.
