# update-site-settings
Use para dados institucionais.

## Regra central
Nunca invente dados. Se uma informação comercial, legal ou de produto não estiver confirmada, mantenha NULL/oculta e registre em PENDENCIAS.md.

## Passos
1. Alterar apenas dado confirmado.
2. Verificar rodapé, contato, mapa e JSON-LD afetados.
3. Validar formatos de telefone/CNPJ/URL quando aplicável.
4. Revalidar site.
## Checklist
- [ ] Fonte confirmada
- [ ] JSON-LD coerente
- [ ] Rodapé coerente
