# a11y-audit
Use antes de release e após mudanças de UI.
## Checklist WCAG 2.2 AA
- [ ] Contraste >= 4.5:1 para texto normal
- [ ] Foco visível
- [ ] Navegação completa por teclado
- [ ] Skip link e landmarks
- [ ] Alvos >= 44px
- [ ] Labels/erros claros
- [ ] Reduced motion
- [ ] Leitor de tela testado nos fluxos críticos
